# Coin Rush

Um jogo clicker feito com HTML, CSS e JavaScript puro. Esta versão inclui bônus relâmpago e missões diárias.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra a pasta `coin-rush` no VS Code.
3. Abra `index.html` no navegador. Se tiver a extensão Live Server, clique com o botão direito em `index.html` e escolha **Open with Live Server**.

## Como jogar
- Clique na moeda grande para ganhar moedas.
- Use a loja para comprar melhorias.
- Robôs geram moedas automaticamente.
- As conquistas são desbloqueadas ao acumular moedas.
- Use o bônus relâmpago para ganhar moedas extras (recarga de 30 segundos).
- Complete as missões diárias para receber recompensas; elas reiniciam a cada dia.
- O progresso é salvo no armazenamento local do navegador.
